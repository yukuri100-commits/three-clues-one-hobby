# Unit 3: Free Time Detectives

An English interactive lesson with 18 free-time activities, three picture clues per activity, spelling practice and partner speaking.

Open [the interactive presentation](unit3-free-time-interactive-v2.html).

Choose **Core 8**, **Extra 10** or **All 18** on the welcome slide. Use Space to reveal the next clue and the arrow keys to change slides.

To use it offline, download the repository ZIP, extract it, and open unit3-free-time-interactive-v2.html in Chrome or Edge. Keep the unit3-assets folder beside the HTML file. The Listen button uses an English voice available on the device.

The illustrations are generated teaching assets. The original single-file lesson embedded every image and exceeded GitHub's regular file-size limit. This repository version stores the same original PNG images in unit3-assets/images and references them from the HTML. Lesson wording, layout, interactions and image bytes are preserved.
